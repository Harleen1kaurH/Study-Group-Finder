# Study-Group-Finder

A full-stack web app for matching students by course and scheduling group study sessions. Students post the courses they need help with, form study groups, and use a propose-vote-confirm workflow to agree on a session time — with in-app notifications and scheduled reminders (24h and 1h before each session) keeping everyone in the loop.

**Stack:** React (Next.js) frontend, FastAPI backend, PostgreSQL database, JWT auth via HttpOnly cookie, APScheduler for scheduled in-app reminders.
